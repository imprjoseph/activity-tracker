# MVP 驗收清單

1. 執行 `setupTracker()` 後，13 張工作表、12 個大項、檢核規則與兩組提醒規則均建立完成。
2. 以三種角色登入，確認主管可見全部案件，PM／同仁只見授權案件，唯讀者不能寫入。
3. 上傳 `sample-import.csv`，確認欄位自動對應、差異預覽與批次紀錄正確。
4. 同一檔案再次以「更新追蹤表」上傳，不會重複新增；修改一列後只出現一筆更新。
5. 移除超過 20% 的既有事項時，未勾二次確認不得寫入。
6. 以「更新進度」上傳，未知列被列為略過，未出現在檔案中的既有事項不得刪除。
7. 在系統內修改已匯入事項後，再匯入同時有變更或刪除的 Excel，該項應列為衝突並保留系統值。
8. 勾選追蹤大項後可看到疑似漏項；「補成任務」與「不適用＋原因」均留下紀錄，全部處理後可確認為「已確認」。
9. 將提醒維持測試模式並設定測試信箱；到期任務依人員與活動合併，信件含批次 ID。
10. 同一時段重跑提醒不會重寄；暫時失敗最多重試三次；完成任務／交辦後，後續批次排除該項。
11. Dashboard 的完成率、準時率、逾期數與人工抽算相同；取消／不適用不進分母，展延後準時率仍以原始期限計算。
12. 管理員可停權帳號但不能停用最後一位管理員；案件成員的唯讀、編輯、管理與移除權限立即生效。
13. 執行手動備份並確認每日排程；從副本演練一次還原，再將結果記錄於 ChangeLog 或外部上線紀錄。
